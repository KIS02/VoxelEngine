   ├─ 착수 조건 (Phase 14 이후 재평가)
   │  ├─ Procedural World / Player Physics / Block Texture / Lighting 안정화
   │  ├─ Rendering Architecture 및 주요 최적화 완료 여부 확인
   │  ├─ 핵심 엔진 개발을 지연시키지 않는 별도 일정 확보
   │  └─ 선택적 기능으로서 구현 가치와 포트폴리오 효과 재검토
   │
   ├─ 16.1 Extra Module Architecture
   │  ├─ 독립 extras/pipeline_playback 모듈
   │  ├─ 빌드 옵션 (예: VE_ENABLE_PIPELINE_PLAYBACK, 기본 OFF)
   │  ├─ 기본 엔진의 필수 Include / Link 의존성 금지
   │  ├─ 모듈을 통째로 제거해도 일반 실행 / Regression 정상
   │  └─ 기존 Phase 8 F4 Inspector / Pipeline Trace 복원하지 않음
   │
   ├─ 16.2 Controlled Scene / Immutable Snapshot
   │  ├─ 고정 Demo Scene의 4 Chunk Mesh / Index / Vertex 데이터 확보
   │  ├─ Model / View / Projection / Texture 등 시각화용 입력 복사
   │  ├─ 실제 World / Gameplay 상태와 독립된 재생 데이터
   │  └─ 정점 / 픽셀 처리량 및 메모리 상한 설정
   │
   ├─ 16.3 Start State / Playback Camera
   │  ├─ Local Mesh 정점들을 원점 부근에 점(Point)으로 표시
   │  ├─ 초기 Orthographic 시점 / 전체 정점이 보이는 Camera
   │  ├─ 게임 Camera와 분리된 교육용 Camera
   │  └─ 최종 화면과 실제 게임 Camera의 시점 일치 계획
   │
   ├─ 16.4 Automatic Timeline & Easing
   │  ├─ 각 Stage 애니메이션 지속 시간 t초 (설정 가능)
   │  ├─ Stage 사이 대기 시간 q초 (마지막 Stage 후에는 대기 없음)
   │  ├─ Smoothstep: s(u) = 3u² - 2u³ (Ease-In-Out)
   │  ├─ Delta Time 기반 재생 / 프레임 시간 초과분 이월
   │  ├─ 자동 순차 재생 (방향키 수동 단계 넘김 없음)
   │  └─ 역방향 재생 기능 없음
   │
   ├─ 16.5 Educational Pipeline Stages
   │  ├─ Local Vertices: 점으로 시작
   │  ├─ World Transform: Chunk별 Model Matrix를 따라 정점 배치
   │  ├─ View Transform: View Matrix 효과와 Camera 연출을 구분
   │  ├─ Projection: Orthographic 초기 표현 → Perspective 시각화
   │  ├─ Primitive Assembly: Index 기반 삼각형 / Edge 연결
   │  ├─ Clipping → Perspective Divide → NDC → Viewport
   │  ├─ Rasterization: 후보 픽셀 / Coverage / Barycentric 단계적 표시
   │  └─ Fragment: Texture Sampling / Depth Test / 최종 색상
   │
   ├─ 16.6 Renderer Integration
   │  ├─ 재생 전용 시각화 Render Path (실제 월드 수정 금지)
   │  ├─ Software / OpenGL에서 동일한 교육용 결과 목표
   │  ├─ 실제 GPU 내부 추적과 CPU 재계산/교육용 연출 명확히 구분
